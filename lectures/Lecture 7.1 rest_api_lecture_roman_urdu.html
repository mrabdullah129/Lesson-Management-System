🔷 Part 1

REST API ka Taaruf (Introduction to REST API)

0 – 20 Minute
📌 API kya hoti hai? (What is an API?)

API (Application Programming Interface) aik aisa set of rules (qawaaed ka majmua) hai jo mukhtalif software systems ko ek doosre se baat karne ki ijazat deta hai.

👉
Asl Zindagi ki Misal (Real-life Example):
Jab aap Foodpanda ya Careem istemaal karte hain, to mobile app server ke saath APIs ki madad se baat karta hai.

App ek request bhejta hai:
"Dastiyaab restaurants dikhao" (Show available restaurants)

Server JSON format mein restaurant ka data bheji se jawaab deta hai.
📌 REST kya hai? (What is REST?)

REST (Representational State Transfer) networked applications design karne ka ek architectural style (mamaari ka andaz) hai.

Yeh in cheezon ka istemaal karta hai:

  • HTTP protocol — data transfer ka tareeqa
  • Standard HTTP methods — GET, POST, PUT, DELETE wagherah
  • Stateless communication — har request apni alag pehchaan rakhti hai
📋 REST ke Usool (REST Principles)
🔄
1. Stateless
Har request mukammal hoti hai — server ko pehli request yaad nahi rehti
🖥️
2. Client-Server Architecture
Client aur Server alag alag kaam karte hain — dono ki zimmedaari alag hai
🔗
3. Uniform Interface
Ek hi andaz mein communicate karna — sab ke liye ek jaisa tareeqa
📦
4. Resource-based
Sab kuch "resource" hai — jaise users, books, orders wagherah
⚡ REST mein istemaal hone waale HTTP Methods
Method Maqsad (Purpose) Asl Zindagi ki Misal (Real-life Example)
GET Data haasil karna (Retrieve data) Product dekhna (View product)
POST Naya data banana (Create data) User register karna (Register user)
PUT Data update karna (Update data) Profile update karna (Update profile)
DELETE Data mitaana (Delete data) Account delete karna (Delete account)

🔷 Part 3

REST API Design ke Behtareen Tareeqe (Best Practices)

40 – 60 Minute
✅ 1. Nouns istemaal karo, Verbs nahi (Use Nouns, Not Verbs)

Endpoints mein hamesha resource ka naam (noun) likho — action (verb) nahi.

❌ /getBooks
✅ /books
✅ 2. Plural Resource Names istemaal karo (Use Plural Resource Names)

Resources ke naamon ko hamesha plural (jamaa) mein likho — singular (wahid) mein nahi.

❌ /book
✅ /books
✅ 3. Sahi HTTP Status Codes istemaal karo (Use Proper HTTP Status Codes)

Server se milne waala response ek status code ke saath aata hai jo batata hai ke kya hua.

200
OK
(Theek hai)
201
Created
(Bana diya)
400
Bad Request
(Galat Request)
404
Not Found
(Nahi Mila)
500
Server Error
(Server ki Ghalti)
✅ 4. JSON Format istemaal karo (Use JSON Format)

REST APIs mein data JSON (JavaScript Object Notation) format mein bheji aur receive kiya jaata hai.

Misal Response (Example Response):

{
  "id": 1,
  "title": "Clean Code",
  "author": "Robert C. Martin",
  "price": 500
}

Step 3: Books API Banao (Create Books API)

📗 GET — Tamam Kitaabein Haasil Karo (GET All Books)

JavaScript 
let books = [];   // Kitaabon ki khaali list

app.get('/books', (req, res) => {
  res.json(books);  // Tamam kitaabein bhejo
});

📘 POST — Nai Kitaab Shamil Karo (POST Book)

JavaScript 
app.post('/books', (req, res) => {
  const book = req.body;  // Request se kitaab ka data lo
  books.push(book);         // List mein shamil karo
  res.status(201).json(book); // 201 = Bana diya
});

📗 GET — ID se Aik Kitaab Haasil Karo (GET Book by ID)

JavaScript 
app.get('/books/:id', (req, res) => {
  const id = parseInt(req.params.id);
  const book = books.find(b => b.id === id);

  if (!book) {
    // Kitaab nahi mili to 404 bhejo
    return res.status(404).json({ message: "Book not found" });
  }
  res.json(book);
});

📙 PUT — Kitaab Update Karo (PUT Update Book)

JavaScript 
app.put('/books/:id', (req, res) => {
  const id = parseInt(req.params.id);
  const index = books.findIndex(b => b.id === id);

  if (index === -1) {
    // Index nahi mila to 404
    return res.status(404).json({ message: "Book not found" });
  }
  books[index] = req.body;     // Naya data rakho
  res.json(books[index]);
});

📕 DELETE — Kitaab Mitao (DELETE Book)

JavaScript 
app.delete('/books/:id', (req, res) => {
  const id = parseInt(req.params.id);
  // Us kitaab ko hata do jis ka id match kare
  books = books.filter(b => b.id !== id);
  res.json({ message: "Book deleted" }); // Kitaab mit gayi
});

🔶 Part 5 — Advanced

Advanced Concepts (Aaala Tareeqe)

100 – 115 Minute
🔍 1. Query Parameters

Query parameters URL ke saath extra malumat bhejne ka tareeqa hai. Yeh URL ke akhir mein ? ke baad likhte hain.

📌
Misal (Example):
Sirf "Ali" ki likhi kitaabein chahiye ho to:
GET /books?author=Ali
📄 2. Pagination (Safha bandi)

Jab kitaabon ya records ki tadaad zyada ho to hum unhe chote hisson (pages) mein taqseem karte hain — yeh Pagination hai.

📌
Misal (Example):
Pehle page par sirf 10 kitaabein lo:
GET /books?page=1&limit=10
🔐 3. Authentication — Bunyaadi Fikr (Basic Concept)

Secure APIs ke liye JWT (JSON Web Token) istemaal karte hain. Yeh ek digital pehchaan patr (ID card) ki tarah hota hai.

🔄 Login Flow (Login ka Silsila):

1
User apni credentials (username/password) bhejta hai (User sends credentials)
2
Server verify karta hai — check karta hai ke credentials sahi hain ya nahi (Server verifies)
3
Server ek token bheji bhejta hai — jaise ek security pass (Server sends token)
4
Client agle requests mein yeh token header mein bhejta hai (Client sends token in header)
