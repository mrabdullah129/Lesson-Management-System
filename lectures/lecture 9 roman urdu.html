🟦 Part 1 — 0 se 30 Minute

TypeScript mein Classes

0–30 min
📌 Class kya hoti hai?

Class ek blueprint (khaka) hoti hai — jiske zariye objects banaye jaate hain.

👉
Aise samjho:
➤ Car ka blueprint → bahut saari cars banaata hai
➤ Student ka template → student ke objects banaata hai
🧾 Syntax Example
TypeScript 
class Student {
  name: string;
  age: number;

  constructor(name: string, age: number) {
    this.name = name;
    this.age = age;
  }

  display(): void {
    console.log(`Name: ${this.name}, Age: ${this.age}`);
  }
}
🔍 Aham Concepts (Key Concepts)
🏷️
Properties
Class ke andar maujood variables
⚙️
Constructor
Object ko initialize karta hai
🔧
Methods
Class ke andar functions
🌍 Asl Zindagi ki Misal (Real-Life Example)
🏦 Bank Account ki Misal

➤ Properties → Account number, Balance
➤ Methods → deposit(), withdraw()

🔐 Access Modifiers

Access modifiers batate hain ke class ki properties aur methods ko kahaan se access kiya ja sakta hai.

Modifier Matlab (Meaning)
public Har jagah se access ho sakta hai
private Sirf class ke andar se access ho sakta hai
protected Class aur us ke subclasses mein access hota hai
💡 Access Modifier ki Misal
TypeScript 
class BankAccount {
  private balance: number;

  constructor(balance: number) {
    this.balance = balance;
  }

  deposit(amount: number) {
    this.balance += amount;
  }
}
💡
Samjhaawa:
private balance ka matlab hai ke balance ko sirf BankAccount class ke andar se hi access kiya ja sakta hai — bahar se nahi.

🟩 Part 2 — 30 se 60 Minute

Inheritance (Warasat)

30–60 min
📌 Inheritance kya hai?

Inheritance ek class ko doosri class ki properties aur methods dobara istemaal karne ki ijazat deta hai — bina unhe dubara likhne ke.

👉
Asl Zindagi ki Misal:
Baccha apne waalidain (parents) se sifaat (traits) wiraasat mein paata hai — bilkul isi tarah ek class doosri se properties le sakti hai.
🧾 Syntax
TypeScript 
class Animal {
  move(): void {
    console.log("Moving...");
  }
}

class Dog extends Animal {
  bark(): void {
    console.log("Barking...");
  }
}
🔍 Aham Keyword
extends

→ yeh keyword Inheritance ke liye istemaal hota hai. Iska matlab hai "wirasat mein lena" ya "extend karna".

🌍 Asl Zindagi ki Misal
🚗 Gaadi (Vehicle) ki Misal

➤ Parent (Waalid) Class: Vehicle — move karne ki ability
➤ Child (Baccha) Classes: Car, Bike — Vehicle se properties wiraasat mein milti hain

🔁 Method Overriding (Tareeqa Badalna)

Jab ek child class apne parent class ke method ko apne andaaz mein dobara define kare, use Method Overriding kehte hain.

TypeScript 
class Animal {
  speak(): void {
    console.log("Animal speaks");   // Janwar bolta hai
  }
}

class Cat extends Animal {
  speak(): void {
    console.log("Cat meows");         // Billi miyaaon karti hai
  }
}
💡
Samjhaawa:
Cat class ne Animal class ka speak() method override kar diya — yani apna alag andaz diya. Ab Cat bolegi "Cat meows".
🧠 Inheritance ke Fayde (Benefits)
  • Code Reuse — Code dobara likhne ki zaroorat nahi
  • Saaf Banawat (Cleaner Structure) — Code zyada munazzam hota hai
  • Aasaan Maintenance — Ek jagah change karo, sab jagah asar hoga

🟨 Part 3 — 60 se 90 Minute

Interfaces

60–90 min
📌 Interface kya hai?

Interface ek contract (muaahida) define karta hai — jise class ko poora karna zaroori hota hai.

👉
Asl Zindagi ki Amsal:
➤ Nokri ka contract → zimmedaariyaan mutayyin karta hai (defines responsibilities)
➤ USB port ka standard → compatibility mutayyin karta hai
🧾 Syntax
TypeScript 
interface Person {
  name: string;
  age: number;
}

class Student implements Person {
  name: string;
  age: number;

  constructor(name: string, age: number) {
    this.name = name;
    this.age = age;
  }
}
🔍 Aham Keyword
implements

→ yeh keyword Interface ke saath istemaal hota hai. Class kehti hai: "Main is interface ka muaahida poora karta hoon."

🌍 Asl Zindagi ki Misal
📐 Shape ki Misal

➤ Interface: Shape
➤ Classes: Circle, Rectangle
➤ Tamam classes ko area() method implement karna zaroori hai

🧠 Interface mein Methods

Interface sirf method ka naam aur return type declare karta hai — implementation nahi karta. Implementation class ka kaam hai.

TypeScript 
interface Shape {
  area(): number;
}

class Circle implements Shape {
  radius: number;

  constructor(radius: number) {
    this.radius = radius;
  }

  area(): number {
    return Math.PI * this.radius * this.radius;
  }
}
🧩 Multiple Interfaces (Kai Interfaces)

Ek class ek se zyada interfaces implement kar sakti hai — yahi iska sabse bada faaida hai!

TypeScript 
interface A { a: number; }
interface B { b: number; }

class Test implements A, B {
  a = 10;
  b = 20;
}
💡
Aham baat:
Test class ne dono interfaces A aur B ko implement kiya — class ke paas a bhi hai aur b bhi.

Muqabala + Practice (Comparison + Practice)

90–120 min
⚖️ Classes vs Interfaces — Muqabala
Feature (Khoobee) 🔷 Class 🔶 Interface
Implementation (Amal) ✅ Haan ❌ Nahi
Object Banana ✅ Haan ❌ Nahi
Constructor ✅ Haan ❌ Nahi
Inheritance (Warasat) ✅ Haan ✅ Haan
Multiple Inheritance ❌ Nahi ✅ Haan
🧠 Kya Istemaal Karo? (When to Use What?)
🔷 Class Kab Istemaal Karo?
Jab aapko implementation (amal) ki zaroorat ho — yani aapko code aur functionality likhni ho jo kaam kare.
🔶 Interface Kab Istemaal Karo?
Jab aapko sirf structure ya contract define karna ho — yani batana ho ke kya hona chahiye, kaise nahi.
🌍 Mili Jali Asl Zindagi ki Misal (Combined Real-Life Example)

Yeh misal dikhaati hai ke Interface, Class, aur Inheritance ko milaa kar kaise istemal karte hain:

Interface VehicleRules — gaari ke qawaaneen define karta hai
Class Car implements VehicleRules — qawaaneen lagu karta hai
Subclass ElectricCar extends Car — Car se warasat leta hai

Class

Inheritance

Interface
