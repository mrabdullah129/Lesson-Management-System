API Calling with Fetch

Fetch browser ka built-in function hai. Ismein aapko manual JSON parsing aur error checking karni parti hai.

The 4 Steps:

  • 01 Call fetch(url)
  • 02 Check response.ok
  • 03 Parse response.json()
  • 04 Update State / Dispatch
// Fetch Example
const getData = async () => {
  try {
    const response = await fetch('/api/products');
    if (!response.ok) 
       throw new Error('Network response error');
    const data = await response.json();
    console.log(data);
  } catch (error) {
    console.error('Fetch error:', error);
  }
};

API Calling with Axios

Axios ek external library hai jo data ko automatically parse karti hai aur Interceptors provide karti hai.

Feature Fetch Axios
Installation Built-in (None) npm install axios
JSON Parsing Manual (.json()) Automatic
Error Handling Check response.ok Auto throws error
Interceptor Example 
axios.interceptors.request.use(config => {
  config.headers.Authorization = `Bearer myToken`;
  return config;
});

03

Action

Ek object jo batata hai kya tabdeeli karni hai {type, payload}.

Redux Thunk: Async Middleware

Redux simple objects ko samajhta hai. Thunk middleware humein functions dispatch karne ki ijazat deta hai taake hum async API calls handle kar sakein.

The Thunk Lifecycle

1

FETCH_START

Loading spinner show karein.

2

API Execution

Wait for data from backend.

3

SUCCESS / FAIL

Data store mein save karein ya error dikhayein.

🏁 Final Revision: Aham Nukat

5 Key Takeaways

  • Fetch built-in hai par manually response.ok aur json() handle karna parta hai.
  • Axios better defaults aur automatic JSON parsing deta hai.
  • Redux shared state ko centralize karta hai.
  • Thunk async logic (API calls) handle karne ka tareeqa hai.
  • Async state hamesha 3 parts mein model karein: Loading, Data, Error.

3 Exam Tips 💡

Fetch vs Axios:

Interceptors, better defaults, aur manual JSON na hona main points hain.

Redux Core Flow:

Dispatch → Action → Reducer → Store → UI update.

Thunk Definition:

"Async middleware that allows functions to receive (dispatch, getState) as arguments."
