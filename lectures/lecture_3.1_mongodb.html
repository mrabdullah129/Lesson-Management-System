Overview — 0 se 5 Minute

MongoDB Kyun Seekhein? 🤔

Jab data flexible ho aur schema baar baar badle — tab SQL ki jagah MongoDB best choice hai. MEAN/MERN stack ka pehla M yahi hai!

📄
JSON-like Documents
Data JSON jaisi flexible documents mein store hota hai — SQL tables ki zaroorat nahi. Har document apna structure rakh sakta hai!
🔌
Native Driver — Low-Level Control
MongoClient se seedha MongoDB se baat karo. Poora control apne haath mein — koi wrapper nahi, koi magic nahi!
🦦
Mongoose — Developer Friendly
Schema validation, middleware, population — Mongoose development ko asaan aur safe banata hai!
🔧
Tools Jo Chahiye
MongoDB Shell, Node.js, npm, VS Code. Install karo: npm install mongodb, npm install mongoose
💡
Ek Line SummaryMongoDB = NoSQL, flexible, document-based database jo MEAN/MERN stack ka base hai. Ye yaad karo!

Collection Validation (MongoDB 3.6+)

Schema enforce karna chahte ho? Collection validator use karo!

MongoDB Shell — Validator 
db.createCollection("books", {
  validator: {
    $jsonSchema: {
      bsonType: "object",
      required: ["title", "price"],
      properties: {
        title: { bsonType: "string" },
        price: { bsonType: "number" }
      }
    }
  }
})

Topic 7 — Aggregation Pipeline

Aggregation Pipeline ⚙️

Aggregation se data process karo — average nikalo, group karo, filter karo. SQL ke GROUP BY jaisa lekin zyada powerful!

🔍
$match
Filter karo — sirf wahi documents jo condition match karein. SQL ka WHERE clause!
📊
$group
Data group karo — author ke hisaab se, category ke hisaab se. $sum, $avg use karo!
🔢
$sort / $project
Sort karo aur sirf chahiye wali fields rakho. $project se unnecessary fields hatao!
Aggregation Examples 
// Average price nikalo
db.books.aggregate([
  { $group: { _id: null, avgPrice: { $avg: "$price" } } }
])

// Author ke hisaab se group karo
db.books.aggregate([
  {
    $group: {
      _id: "$author",
      totalBooks: { $sum: 1 },
      avgPrice: { $avg: "$price" }
    }
  }
])

// Pehle filter, phir count
db.books.aggregate([
  { $match: { price: { $gt: 20 } } },
  { $group: { _id: null, count: { $sum: 1 } } }
])
📌
Exam ke liye Yaad Rakho!Aggregation pipeline stages hain: $match (filter), $group (group karo), $sort (sort karo), $project (fields chuno). Ye sequence yaad rakhna!

Basic Connection

index.js — Connection 
const { MongoClient } = require('mongodb');
const uri = 'mongodb://localhost:27017/bookstore';

async function main() {
  const client = new MongoClient(uri);
  try {
    await client.connect();
    console.log('Connected to MongoDB!');
    const db = client.db('bookstore');
    // yahan operations karo...
  } catch (e) {
    console.error(e);
  } finally {
    await client.close();
  }
}
main();

Topic 9 — 70 se 105 Minute

Mongoose — Schema aur Models 🦦

Mongoose = ODM (Object Document Mapper). Schema define karo, Model banao, aur CRUD operations easily karo — validation bhi free mein!

📋
Schema kya hai?
Document ka structure define karta hai — kaunsi fields hongi, unka type kya hoga, kya required hai. MongoClient mein ye nahi hota!
🏗️
Model kya hai?
Schema se banta hai — ek class jo CRUD ke liye use hoti hai. Book.find(), Book.save() — sab Model se!
✅
Validation
required: true, min: 0 — Schema mein rules set karo. Galat data save hi nahi hoga!
🔗
Extra Features
Middleware (hooks), Population (joins), Easier queries — MongoClient se kaafi zyada features!

app.js — Schema aur Model 
const mongoose = require('mongoose');

// Database se connect karo
mongoose.connect('mongodb://localhost:27017/bookstore')
  .then(() => console.log('Connected!'));

// Schema define karo — structure aur validation
const bookSchema = new mongoose.Schema({
  title:  { type: String, required: true },
  author: String,
  price:  { type: Number, min: 0 }
});

// Model banao Schema se
const Book = mongoose.model('Book', bookSchema);

CRUD Operations — Mongoose Style

app.js — CRUD 
async function crud() {

  // CREATE — naya book banao aur save karo
  const book = new Book({
    title: "Mongoose Guide",
    author: "Lim",
    price: 15
  });
  await book.save();

  // READ — filter se dhundho
  const books = await Book.find({ price: { $gt: 10 } });
  console.log(books);

  // UPDATE — title dhundho aur price badlo
  await Book.updateOne(
    { title: "Mongoose Guide" },
    { $set: { price: 20 } }
  );

  // DELETE — document hatao
  await Book.deleteOne({ title: "Mongoose Guide" });
}
crud();

Validation Test karo!price: -5 dene ki koshish karo — Mongoose reject kar dega kyunki min: 0 set hai. Ye MongoClient mein nahi hota!

MongoClient vs Mongoose — Farq kya hai?

FeatureMongoClientMongoose
SchemaNahi hota✅ Schema define hota hai
ValidationManual karna parta hai✅ Built-in validation
Middleware / Hooks❌ Nahi✅ pre/post hooks
Population (joins)❌ Nahi✅ .populate() available
Control LevelLow-level, zyada controlHigh-level, easy API
Use CaseSimple scripts, microservicesFull apps, REST APIs
