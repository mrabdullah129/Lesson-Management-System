MEAN Stack "End-to-End" Mental Model

Explanation (Wazahat)

MEAN stack aik full-stack pipeline hai jahan React UI HTTP requests bhejti hai, Express/Node unko process karte hain, aur MongoDB mein data store hota hai. Yaad rakhen, client aur server separate hote hain; UI direct database se baat nahi karti, balkay API ke zariye communicate karti hai.

🚀 Request Flow

  • 1 React action trigger hota hai
  • 2 API call (fetch/axios) jati hai
  • 3 Express request receive karta hai
  • 4 Mongoose DB query karta hai
  • 5 Server JSON response bhejta hai
  • 6 React UI update karta hai

REST API Design

REST endpoints resources (maslan tasks, users) ko represent karte hain. Hum HTTP methods use karte hain specific actions ke liye:

Action HTTP Method Route Status Code
Get All Tasks GET /tasks 200 OK
Create Task POST /tasks 201 Created
Update Task PATCH/PUT /tasks/:id 200 OK
Delete Task DELETE /tasks/:id 204 No Content

Backend Live Build (Express + Mongoose)

Core Concepts

Express app routing handle karta hai, aur Mongoose JS objects ko MongoDB documents se map karta hai.

// Essential Middleware

app.use(express.json()); // req.body parse karne ke liye

app.use(cors()); // Frontend access allow karne ke liye

Why CORS?

React dev server (port 3000) aur API (port 5000) alag hote hain. CORS allow karta hai ke browser blocks na kare cross-origin requests ko.

React Core Concepts

Props vs State

📦

Props

  • Parent-owned (Bahir se aata hai)
  • Read-only (Nahi badal sakte)
  • Data passing ke liye use hota hai
  • Functional approach
💾

State

  • Component-owned (Apna private data)
  • Mutable (Setter se change hota hai)
  • UI updates trigger karta hai
  • Dynamic behavior store karta hai

Lifecycle via Hooks

useEffect Hook

Hooks ne puranay class methods ko replace kar dia hai. useEffect side effects handle karta hai (maslan API data fetching).

Pro Tip

Dependency array [] ka sahi istemal zaroori hai warna infinite loop ban sakta hai.

Async Fetch Pattern

  1. 1 Set state to 'loading'
  2. 2 Call API (await fetch)
  3. 3 Update state with data
  4. 4 Handle potential errors
  5. 5 Set loading to 'false'
