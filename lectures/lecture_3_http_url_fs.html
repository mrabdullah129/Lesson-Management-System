HTTP Server Kyun Seekhein? 🤔

Express jaisa framework use karne se pehle, seedha http module samajhna zaroori hai — taake real apps mein kuch bhi galat ho to fix kar sako!

🌐
Framework ke Bina Server
Node.js ka http module seedha low-level server banata hai. Express ke andar bhi yehi hai — pehle ye samjho!
🔗
URL Parsing
Har request ke sath URL aata hai — pathname aur query parameters nikalne ke liye URL module use karte hain!
📁
File System (FS)
Files padhna, likhna, aur stream karna — logs, uploads, static files — sab FS module se hota hai!
🌊
Streams — Memory Bachao
Badi files seedha RAM mein load mat karo — Streams se chunks mein process karo. pipe() magic hai!
💡
Ek Line SummaryNode.js = HTTP server + URL parsing + FS + Streams — ye charon mil ke ek complete web server banate hain! Ye yaad karo!

Part A — Core Concepts

HTTP Basics — Node.js mein 🌐

HTTP ek request/response protocol hai — client request karta hai, server respond karta hai. Node mein ye bilkul seedha hai!

Pehla HTTP Server — Smallest Example

server.js 
const http = require('http');

const server = http.createServer((req, res) => {
  res.statusCode = 200;   // 200 = OK
  res.setHeader('Content-Type', 'text/plain; charset=utf-8');
  res.end('Hello from Node HTTP server!\n');
});

server.listen(3000, () => {
  console.log('Server chal raha hai: http://localhost:3000/');
});
🚀
Try Karo!node server.js chalao, browser mein http://localhost:3000 kholo. Ya terminal mein: curl -i http://localhost:3000

Part B — URL Module

URL Module — URL ko Tukron mein Todno 🔗

URL class se pathname aur query parameters alag karo — string split karne se zyada safe aur reliable!

📍
pathname
/products/42 — route path. Routing ke liye ye use hota hai!
❓
searchParams
?q=node&limit=10 — query string. get('q') se value nikalo!
#️⃣
hash
#section — fragment. Ye browser side hota hai, server tak nahi aata!
server.js — URL Parsing 
const { URL } = require('url');

function parseUrl(req) {
  // base zaroor dena — req.url relative hota hai
  const base = `http://${req.headers.host}`;
  return new URL(req.url, base);
}

// Example use:
const u = parseUrl(req);
console.log(u.pathname);                   // '/search'
console.log(u.searchParams.get('q'));    // 'node'
📌
Exam ke liye!URL class use karne ke liye base zaroor dena parta hai — kyunki req.url relative hota hai (e.g., /search), poora URL nahi. Ye point yaad rakho!
Part C — Routing

Routing — Sahi Jagah Sahi Kaam 🚦

Routing matlab: HTTP method + URL pathname dekho aur sahi handler function chalao. Express bhi yehi karta hai — andar se!

server.js — Routes Object Pattern 
const http = require('http');
const { URL } = require('url');

// Sare routes ek object mein
const routes = {
  'GET /': (req, res) => {
    res.writeHead(200, { 'Content-Type': 'text/plain; charset=utf-8' });
    res.end('Home Page\n');
  },
  'GET /api/time': (req, res) => {
    const payload = { now: new Date().toISOString() };
    res.writeHead(200, { 'Content-Type': 'application/json; charset=utf-8' });
    res.end(JSON.stringify(payload));
  }
};

// Main handler function
function handler(req, res) {
  const u = new URL(req.url, `http://${req.headers.host}`);
  const key = `${req.method} ${u.pathname}`;
  const fn = routes[key];

  if (!fn) {
    res.writeHead(404, { 'Content-Type': 'text/plain; charset=utf-8' });
    return res.end('404 Not Found\n');
  }
  fn(req, res, u);
}

http.createServer(handler).listen(3000);
console.log('Listening on http://localhost:3000');
💡
Teaching NoteYe intentionally simple hai. Express mein middleware, parameterized routes aur error handling extra hoti hai — lekin andar se yehi logic hai!
Part D — File System

File System (FS) — Files Padhna aur Likhna 📁

fs module se files padhte hain, likhte hain. Server mein hamesha async APIs use karo — warna event loop block ho jaega!

🔴
Synchronous — Blocking
fs.readFileSync(), fs.writeFileSync() — ek kaam karte waqt dusra kuch nahi hota. Server mein mat use karo!
✅
Async — Non-Blocking
fs.promises.readFile() ya callback style — file padh raha hai lekin server doosri requests handle karta rehta hai!

Async File Read — Promise Style

fileRead.js 
const fs = require('fs/promises');

async function readTextFile(filePath) {
  // utf8 dene se Buffer ki jagah string milti hai
  const data = await fs.readFile(filePath, 'utf8');
  return data;
}

readTextFile('./hello.txt')
  .then(content => console.log(content))
  .catch(err => console.error(err));
API StyleMethodServer mein Use?
Synchronousfs.readFileSync()❌ Mat karo — blocking!
Callback Asyncfs.readFile(path, cb)✅ Ho sakta hai
Promise Asyncfs.promises.readFile()✅ Best choice!
Streamfs.createReadStream()✅ Bari files ke liye
⚠️
Server mein Rule!Hamesha async APIs use karo — readFileSync use karne se server ki ek request doosri sab requests rok deti hai!
Part E — Streams

Streams aur pipe() — Smart Data Bhejne ka Tarika 🌊

Stream data ko chhote chhote chunks mein process karta hai. Bari files ke liye ideal — poori file RAM mein load nahi hoti!

📖
Readable Stream
Data padhne ka source — file, HTTP request body, database response. fs.createReadStream() readable hai!
✍️
Writable Stream
Data likhne ki jagah — HTTP response, file, console. res object writable stream hai!
🔧
pipe()
Readable ko Writable se connect karo! Backpressure khud handle karta hai — memory safe rehti hai!
server.js — Stream File to Response 
const fs = require('fs');

function streamFileToResponse(filePath, res) {
  const fileStream = fs.createReadStream(filePath);

  fileStream.on('error', (err) => {
    // ENOENT = file nahi mila, EACCES = permission nahi
    res.writeHead(404, { 'Content-Type': 'text/plain; charset=utf-8' });
    res.end('File not found\n');
  });

  res.writeHead(200, { 'Content-Type': 'application/octet-stream' });
  fileStream.pipe(res);  // chunks mein data jata hai + backpressure!
}
💧
Backpressure kya hota hai?Agar network slow hai to response data utni jaldi nahi le sakta jitni jaldi file deta hai. pipe() dono ki speed coordinate karta hai — memory overflow nahi hoti!
Part F — Examples

Real Examples — JSON API aur Static Files 💡

Do complete examples — ek JSON API aur ek static file server. Dono milake ek chhota sa web server ban jaata hai!

Example A — JSON API with Query Params

GET /api/echo?msg=hello — query param lo, JSON mein wapas bhejo!

server.js — JSON Echo API 
const http = require('http');
const { URL } = require('url');

http.createServer((req, res) => {
  const u = new URL(req.url, `http://${req.headers.host}`);

  if (req.method === 'GET' && u.pathname === '/api/echo') {
    const msg = u.searchParams.get('msg') ?? '';
    const payload = { ok: true, msg };
    res.writeHead(200, { 'Content-Type': 'application/json; charset=utf-8' });
    return res.end(JSON.stringify(payload));
  }

  res.writeHead(404, { 'Content-Type': 'text/plain; charset=utf-8' });
  res.end('Not Found\n');
}).listen(3000);

Example B — Static File Server (Security ke Sath)

public/ folder se files serve karo — path traversal se bhi protected!

server.js — Static File Server 
const http = require('http');
const fs   = require('fs');
const path = require('path');
const { URL } = require('url');

const publicDir = path.join(__dirname, 'public');

// File extension se Content-Type decide karo
function contentType(filePath) {
  const ext = path.extname(filePath).toLowerCase();
  return ({
    '.html': 'text/html; charset=utf-8',
    '.css':  'text/css; charset=utf-8',
    '.js':   'application/javascript; charset=utf-8',
    '.json': 'application/json; charset=utf-8',
    '.png':  'image/png',
    '.jpg':  'image/jpeg'
  })[ext] || 'application/octet-stream';
}

// Security: public folder se bahar nahi jaane dena!
function safeJoin(base, target) {
  const targetPath = path.normalize(path.join(base, target));
  if (!targetPath.startsWith(base)) return null;
  return targetPath;
}

http.createServer((req, res) => {
  const u = new URL(req.url, `http://${req.headers.host}`);
  let reqPath = decodeURIComponent(u.pathname);
  if (reqPath === '/') reqPath = '/index.html';

  const filePath = safeJoin(publicDir, reqPath);
  if (!filePath) {
    res.writeHead(400); return res.end('Bad Request\n');
  }

  const stream = fs.createReadStream(filePath);
  stream.on('error', () => {
    res.writeHead(404); res.end('File Not Found\n');
  });
  res.writeHead(200, { 'Content-Type': contentType(filePath) });
  stream.pipe(res);
}).listen(3000);
🔐
Security — Path Traversal!User /../secret.txt jaisa path de ke public folder se bahar ja sakta hai. safeJoin() function ye rokta hai — path normalize karo aur check karo ke base se shuru hota hai!
Debugging Clinic

Debugging Clinic 🐛

Sabse common errors aur unka hal — ye yaad rakho to kabhi phase nahi khao ge!

🔴
res.end() bhool gaye!Agar response end nahi kiya to browser hanging rehta hai. Hamesha res.end() call karo ya pipe() use karo!
🔴
Galat Content-Type!JSON bhej rahe ho to application/json lagao — text/plain se browser confuse hota hai aur JSON parse nahi karta!
🔴
readFile bari file ke liye!Bari files ke liye readFile() puri file RAM mein load kar leta hai. Server crash ho sakta hai — createReadStream() use karo!
💡
Pro TipHamesha stream aur fs errors handle karo — unhandled errors se server crash ho jaata hai. try/catch aur .on('error') zaroor lagao!
