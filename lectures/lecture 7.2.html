Part 1: API & REST ka Introduction (0 – 20 min)

API kya hoti hai?

API ka matlab hai Application Programming Interface.

👉 Real-life Example:

Restaurant waiter ke baare mein sochen:

  • Aap (client) order dete hain.
  • Waiter (API) order kitchen (server) tak pohanchata hai.
  • Kitchen food prepare karta hai.
  • Waiter food wapas aap ke paas le aata hai.

So:

Client
Frontend
Server
Backend
API
Communication bridge

REST kya hai?

REST ka matlab hai Representational State Transfer.

Yeh web services bananay ke liye aik architectural style hai.

Yeh HTTP protocol use karta hai.

Part 2: REST Principles (20 – 40 min)

REST 6 main principles par based hota hai:

1️⃣ Client-Server Architecture

Frontend aur backend separate hotay hain.

2️⃣ Stateless

Har request mein tamam zaroori information honi chahiye.

Server client session store nahi karta.

Example: Har dafa jab aap ATM par jatay hain, aap card dobara insert kartay hain.

3️⃣ Cacheable

Responses performance improve karne ke liye cache kiye ja sakte hain.

4️⃣ Uniform Interface

Standard URL aur HTTP methods use hotay hain.

5️⃣ Layered System

Security layer, database layer waghera ho sakti hain.

6️⃣ Code on Demand (Optional)

Yeh optional principle hai.

HTTP Methods in REST

Method Purpose Example
GET Data retrieve karna Student list get karna
POST Naya data create karna Student add karna
PUT Data update karna Student update karna
DELETE Data delete karna Student remove karna

Step 4: CRUD Operations implement karna

GET All Students

GET /api/students
app.get('/api/students', (req, res) => {
  res.json(students);
});

GET Student By ID

GET /api/students/:id
app.get('/api/students/:id', (req, res) => {
  const student = students.find(s => s.id == req.params.id);

  if (!student) {
    return res.status(404).json({ message: "Student not found" });
  }

  res.json(student);
});

POST Create Student

POST /api/students
app.post('/api/students', (req, res) => {
  const newStudent = {
    id: students.length + 1,
    ...req.body
  };

  students.push(newStudent);
  res.status(201).json(newStudent);
});

PUT Update Student

PUT /api/students/:id
app.put('/api/students/:id', (req, res) => {
  const student = students.find(s => s.id == req.params.id);

  if (!student) {
    return res.status(404).json({ message: "Student not found" });
  }

  student.name = req.body.name;
  student.email = req.body.email;
  student.department = req.body.department;

  res.json(student);
});

DELETE Student

DELETE /api/students/:id
app.delete('/api/students/:id', (req, res) => {
  students = students.filter(s => s.id != req.params.id);
  res.json({ message: "Student deleted successfully" });
});
