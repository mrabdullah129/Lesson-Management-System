Part 1 - 0 se 20 Minute

Introduction to Express & Application Architecture

Express.js Node.js ke upar bana hua minimal aur flexible web framework hai. Ye developers ko web servers, APIs aur HTTP request-response handling mein help karta hai.

❓
What is Express?
Express.js ek minimal aur flexible web framework hai jo Node.js ke upar build hota hai.
🔧
Express kis kaam aata hai?
Web servers banana, APIs create karna, aur HTTP requests/responses ko handle karna.
💡
Real-Life Analogy - Restaurant ManagerCustomers = Client (Browser/Postman), Orders = Requests, Kitchen = Server logic, Waiter = Middleware, Manager = Express.

Basic Express App Structure

app.js 
const express = require('express');
const app = express();

app.get('/', (req, res) => {
  res.send("Welcome to Express!");
});

app.listen(3000, () => {
  console.log("Server running on port 3000");
});
ComponentMatlab
appApplication object. Is ke through Express app control hoti hai.
app.get()Route define karta hai jo GET request handle karta hai.
reqRequest object. Client ki request ka data rakhta hai.
resResponse object. Server ka jawab client ko send karta hai.
app.listen()Server start karta hai aur given port par listen karta hai.
Part 2 - 20 se 40 Minute

Middleware Concepts

Middleware ek aisa function hota hai jo request receive hone ke baad aur response send hone se pehle execute hota hai.

Request Receive
→
Middleware
→
Route Handler
→
Response Send
req
Request Object
Middleware ke paas req object ka access hota hai.
res
Response Object
Middleware response object ko bhi access kar sakta hai.
next
Next Function
next() next middleware ya route handler ko call karta hai.
📌
DefinitionMiddleware functions wo functions hotay hain jin ke paas request object, response object, aur next middleware function ka access hota hai application ke request-response cycle mein.
✈
Real-Life Example - Airport SecurityPassenger arrives = Request. Passport check = Middleware 1. Baggage scan = Middleware 2. Boarding gate = Route handler.

Types of Middleware

1
Application-Level Middleware
Ye app.use() ke through poori application level par use hota hai.
app.use((req, res, next) => {
  console.log("Request received");
  next();
});
2
Router-Level Middleware
Ye Router objects ke andar use hota hai, yani specific route group ke liye middleware.
3
Built-in Middleware
express.json() JSON parse karta hai. express.static() static files serve karta hai.
4
Error-Handling Middleware
Errors ko handle karne ke liye 4 parameters wala middleware use hota hai.
app.use((err, req, res, next) => {
  res.status(500).send("Something broke!");
});
⚡
Middleware Powerful kyun hai?Authentication, logging, data validation aur error handling jaise important kaam middleware ke through clean tarah handle hotay hain.

Routing in Express

Routing ka matlab hai: application kisi specific endpoint par aane wali client request ka response kaise deti hai.

Basic Route 
app.get('/about', (req, res) => {
  res.send("About Page");
});

Route Methods

GET
Read Data
Client server se data get karta hai.
POST
Create Data
Client new data server ko send karta hai.
PUT
Update Data
Existing data ko update karne ke liye.
DELETE
Delete Data
Existing data delete karne ke liye.
🗺
Real-Life Analogy - Google MapsRouting Google Maps jaisi hoti hai. Different routes different destinations tak le jaate hain. URL decide karta hai kaunsa function run hoga.

Route Parameters

app.get('/user/:id', (req, res) => {
  res.send(`User ID: ${req.params.id}`);
});

Part 4 - 70 se 90 Minute

Express Router

Router routes ko different files mein separate karne aur large application ko clean organize karne ke liye use hota hai.

📁
Router kya karta hai?
Routes ko different files mein separate karta hai, large applications ko organize karta hai, aur app ko scalable aur clean banata hai.
⚠
Router kyun zaroori hai?
Agar project mein 50 routes aur multiple modules hon, sab kuch ek file mein rakhna messy aur unmanageable ho jata hai.

Example: Using Router

routes/user.js 
const express = require('express');
const router = express.Router();

router.get('/', (req, res) => {
  res.send("All Users");
});

router.get('/:id', (req, res) => {
  res.send("Single User");
});

module.exports = router;
main app.js 
const userRoutes = require('./routes/user');

app.use('/users', userRoutes);
✅
Ab URLs kya banain ge?/users all users route ko hit karega. /users/10 single user route ko hit karega.
🏫
Real-Life Example - University DepartmentsRouter university departments jaisa hai: Admission Office = /admissions, Accounts Office = /accounts, Examination Office = /exams. Har department apna kaam handle karta hai.

Application Architecture in Express

Large Express application ko scalable banane ke liye routes, middleware, controllers aur models ko proper folders mein arrange karna chahiye.

Recommended Folder Structure

project structure 
project/
|
|-- app.js
|-- routes/
|   |-- user.js
|   |-- product.js
|
|-- middleware/
|   |-- auth.js
|   |-- logger.js
|
|-- controllers/
|   |-- userController.js
|
|-- models/

MVC Pattern in Express

M
Model
Database logic handle karta hai.
V
View
Frontend ya UI layer, jaise EJS/React etc.
C
Controller
Business logic handle karta hai.

Adding Routes Properly

Instead of 
app.get('/users', handler);
Use 
router.get('/', userController.getUsers);
📈
Is approach ke benefitsReadability improve hoti hai, maintainability behtar hoti hai, aur scaling easy ho jati hai.

Middleware Order Matters

Express middleware ko order mein execute karta hai. Is liye kis middleware ko pehle lagana hai, ye bohat important hota hai.

order example 
app.use(logger);
app.use(auth);
app.use('/users', userRoutes);
⚠
ImportantAgar auth fail ho jaye to route execute nahi hota. Is liye middleware order ko hamesha carefully design karo.
