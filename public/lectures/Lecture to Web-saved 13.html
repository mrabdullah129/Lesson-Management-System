01 Why React? & Roadmap

React UI building ko components mein divide karta hai. Jab bhi data (state) change hota hai, React automatically UI ko update kar deta hai efficiently. Apps ek "component tree" ki tarah hoti hain jahan data upar se niche (props) jata hai aur events niche se upar (callbacks).

"React = Components + State + Virtual DOM"

Components: Props vs State

Props (The Inputs)

Props "Read-only" hotay hain. Parent component child ko data pass karta hai (jaise function arguments). Child inhein change nahi kar sakta.

State (The Brain)

State component ki apni memory hoti hai. Jab ye change hoti hai (via useState), component dobara render hota hai.

// Example Component 
function ProductCard({ name, price }) {
  // State to track "Liked" status
  const [liked, setLiked] = useState(false);

  return (
    <div>
      <h2>{name}</h2>
      <p>Price: {price}</p>
      <button onClick={() => setLiked(!liked)}>
        {liked ? '❤️' : '🤍'}
      </button>
    </div>
  );
}

Controlled vs Uncontrolled Forms

Controlled

React state hi "Single Source of Truth" hai. Input ki har tabdeeli state update karti hai. Best for validation.

  • ✅ Instant Feedback
  • ✅ Complex Validation
  • ❌ More Re-renders
Uncontrolled

Data DOM ke pas hota hai. Hum useRef() ke zariye value read karte hain. Best for simple forms.

  • ✅ Less Boilerplate
  • ✅ Higher Performance
  • ❌ No Instant Validation

Hooks Crash Pack (Functional Superpowers)

useState Memory

Functional component mein state handle karne ke liye. Jab state badalti hai, UI update hota hai.

const [val, setVal] = useState(0);
useEffect Effects

Side-effects ke liye (API calls, timers). Empty dependency array [] ka matlab hai "Run only once".

useEffect(() => { ... }, []);
useRef DOM Access

Direct DOM elements ko access karne ya values ko persist karne ke liye (bina re-render ke).

const inputRef = useRef(null);
useContext Global State

"Prop Drilling" se bachne ke liye global state share karne ka tarika (jaise Theme ya User Auth).

const theme = useContext(ThemeCtx);
